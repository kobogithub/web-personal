# ProjectList

Grilla de proyectos. Abre con etiquetas y estrellas, cierra con los enlaces disponibles o el cartel de proyecto interno.

```tsx
<ProjectList projects={[
  { name: 'Knowledge CLI', description: 'CLI en Rust para desarrollo asistido por IA.', tags: ['Rust'], detailHref: '/projects/knowledge-cli/' }
]} />
```
