# Prose

Envoltorio tipográfico para contenido largo — el cuerpo de un post. Aplica la escala de títulos del panel y se invierte solo en tema oscuro.

```tsx
<Prose>
  <h2>Dos planos</h2>
  <p>El plano de control y el de datos se mueven a distinta velocidad.</p>
</Prose>
```
