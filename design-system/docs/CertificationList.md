# CertificationList

Certificaciones en tarjetas con marcas de retícula que se encienden en hover. Nombre, emisor, fecha, verificación e insignia.

```tsx
<CertificationList certifications={[
  { name: 'AWS Solutions Architect', issuer: 'Amazon Web Services', date: '2024', verifyUrl: 'https://…' }
]} />
```
