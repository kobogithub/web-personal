# SkillsList

Grilla de tecnologías. Borde superior de acento, marcas de retícula y resplandor en hover; entra alternando el lado.

```tsx
<SkillsList skills={[
  { name: 'Rust', description: 'Herramientas CLI de alto rendimiento.', icon: 'simple-icons:rust', tags: ['Systems'] }
]} />
```
